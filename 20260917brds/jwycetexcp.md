# 定了！8月1日，市一医院城北新院区投入试运行

> 更新时间：2026-09-17 (UTC+8)

历时五年建设，杭州市第一人民医院城北新院区如期建成，将于**8月1日**起投入试运行。杭州城北居民将迎来一家集临床医疗、教学科研、预防保健及人文关怀为一体的三级甲等综合性医院。

**医院介绍 **

  //  

杭州市第一人民医院城北新院区位于拱墅区沈半路469号，按800张床位规模和三级甲等医院标准建设。通过一体化管理模式，市一医院集中整合两院区学科资源，在城北院区积极打造“三大中心”（胸痛中心、卒中中心、创伤中心），做大做强心脑血管疾病、代谢内分泌疾病、创面修复与再生医学、老年医学、国医中心、康复中心、老年肿瘤学等学科，彰显老年医学科在长三角区域品牌影响力，探索全生命周期管理，满足多元化健康需求。

**试运行公告 **

  //  

鉴于目前新院区部分特殊医疗设备仍需安装调试，为保证医疗质量和医疗安全，试运行期间，**先期开放****康复医学科、临床心理科、中医科、口腔科、肿瘤内科、神经内科、内分泌科、普内科、妇科、皮肤科、耳鼻咽喉科、眼科、骨科、普外科**等25个临床专业普通门诊、专家门诊及相应检验、CT、磁共振、超声等特殊检查治疗；暂不开放急诊、手术室、ICU、输液室、发热门诊、肠道门诊等医疗服务。
