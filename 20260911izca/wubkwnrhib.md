# 抗疫行动丨“国家队”出征小汤山，北大医院再出发

> 更新时间：2026-09-11 (UTC+8)

这是5月5日

北大医院医疗队

在即将奔赴小汤山方舱医院

执行任务前的铮铮誓言。

北京大学常务副校长、医学部主任乔杰院士在队旗上签名

根据国务院应对新型冠状病毒肺炎疫情联防联控机制要求，北京大学第一医院迅速组建支援小汤山方舱医院医疗队，随时待命出发。5月5日一早，第一批由43名医护人员组成的医疗队集结出征，国家卫生健康委医政医管局监察专员郭燕红、国家卫生健康委医政医管局公共卫生医疗管理处处长黄欣、北京市卫生健康委副主任高坚、北京大学常务副校长、医学部主任乔杰、北大医院党委书记姜辉、院长刘新民等领导来到筑梦厅为队员们壮行加油。

院长刘新民主持出征仪式
近期全国疫情防控形势依然严峻，疫情新增病例仍处于高位运行状态。作为国家、首都疫情防控医疗救治的中坚力量，自2021年以来，北大医院已派出近2000人次的核酸采样人员，完成100多次各类指令性任务，共完成核酸采样40余万人次；不断提升核酸检测能力，先后多次提速核酸检测的实验室建设，目前已基本达到国家要求的单日3万管的检测能力；后勤保障同志坚持“主动对接、提前预判、按需保障、及时供给”的原则，科学调配疫情防控物资，为抗疫前线保驾护航。真正的拼出了疫情防控加速度，搏出了人民健康进行时。

出征仪式上，我院副院长王鹏远介绍了医疗队人员构成情况。医疗队由8名医生、32名护士、3名行政管理人员组成。这支医疗队的所有成员，都是医院医疗卫生战线上的业务骨干。自疫情发生以来，大家始终奋战在疫情防控第一线，不辞辛苦、不畏艰险，为守护人民的生命健康作出了重要贡献。

党旗所指，冲锋所向，面对急难险重的工作任务，正是共产党员担当使命之时。党委副书记张静宣读了《关于成立北京大学第一医院支援小汤山方舱医院医疗队临时党支部的通知》，任命徐京杭同志担任医疗队临时党支部书记、王晓月同志担任医疗队临时党支部副书记。

医疗队临时党支部书记徐京杭在发言中表示，感谢上级对北大医院的信任和肯定，党支部将充分发挥战斗堡垒作用和共产党员的先锋模范作用，身先士卒、团结一致，让党旗高高飘扬在抗疫一线。医疗队对于圆满完成本次支援任务充满了信心，将努力发扬厚道精神，从建设、管理到清零，以最高效率和最优质量书写首都疫情防控和医疗救治的新篇章。

医院党委书记姜辉发表了鼓舞人心的讲话。同时间赛跑、与病毒较量，作为国家队，北大医院坚决贯彻习近平总书记重要指示精神和党中央部署要求，坚决扛起政治责任。本次支援小汤山方舱医院，大家主动请缨、踊跃参战，传递着北大医院厚德尚道的精神。大家此行带着光荣的使命，承载着神圣的职责，一定要弘扬“生命至上、举国同心、舍生忘死、尊重科学、命运与共”的伟大抗疫精神，发挥党支部战斗堡垒作用和党员先锋模范作用，坚决完成任务，展现出精湛的医术、良好的品格和扎实的作风。待到凯旋而归时，我们再相聚！

作为亲临武汉一线的巾帼英雄，北京大学常务副校长、医学部主任乔杰院士深情回顾了两年前武汉抗疫的点点点滴滴，并表达了对大家的关心和关怀，同时乔校长向医疗队员们提出了几点希望：一是希望队员们牢记使命、不负重托，以过硬作风和专业优势为生命接力、为健康护航；二是希望队员们严格遵守疫情防控的各项规定，做好自身防护、保重自己身体；三是希望队员们在前线安心、放心地投入战斗，大家的身后是北京大学、北大医学和北大医院的坚定支持。希望大家在抗疫前线以精湛的医术和大爱无疆的精神弘扬新时代北大医学人的厚道精神，奋力践行北大医学人的担当，祝愿大家早传捷报，平安凯旋。

北京市卫生健康委副主任高坚在讲话中对于医疗队寄予重托。在2003年“非典”肆虐首都之时，北大医院即全程参与了小汤山医院的筹建及医疗救治工作，并发挥了重要的示范作用，北大医院的优良作风、专业优势、工作经验和工作模式受到了上级和同行的肯定，是一支能打硬仗、敢打硬仗、打赢硬仗的精锐力量。2022年再次出征小汤山，希望大家继续发挥专业优势，探索疫情防控新常态下的医疗救治经验，始终坚持首善标准，努力践行红墙意识，筑就首都疫情防控的坚实屏障，再次书写小汤山救治新成绩。

国家卫生健康委医政医管局监察专员郭燕红对医疗队表达了期望。2020年初之时，北大医院先后三批派出援鄂抗疫国家医疗队，在武汉承担了最困难、最危重的工作，以科学高效和充满人文关怀的医疗救治实现了提高救治率、降低死亡率的工作目标。两年多来，北大医院统筹医疗服务和疫情防控工作，以扎实工作和一流水平探索出了成功经验，在医疗救治、院感防控、预检分诊、核酸采样、疫苗接种等工作中发挥了标杆作用，充分展现了国家队的使命担当和一流水平。此次启用小汤山方舱医院后，首战即派北大医院医疗队，精锐尽出，希望医疗队坚定信心，打胜仗、零感染，为疫情防控贡献北大智慧和北大力量。

与会人员齐声合唱《团结就是力量》，大家用歌声唱响奋进的力量,用激情点燃奋斗的火把。气势磅礴的歌声中唱出了北大医院人的豪迈，也唱出了北大医院人的精气神儿，更为医疗队员们加油鼓劲。队员们纷纷表示一定不辱使命、不负重托，以实际行动践行展现北大医院人“国家召唤、使命必达”的家国情怀。
