# 胚胎冷冻适应征和指征

> 更新时间：2026-09-16 (UTC+8)

**胚胎冷冻适应征：
**
1. 促排卵周期胚胎移植后有临床意义的剩余胚胎需要保存的。

2. 促排卵周期发生严重OHSS，为防止妊娠后病情加重，需将胚胎保存至以后移植。

3. 促排卵周期进行胚胎移植时插管入宫腔失败或非常困难，对子宫刺激较大，不利于着床，取消移植，需将胚胎保存至以后移植。

4. 其他特殊情况取消移植，需将胚胎保存至以后移植。

Day3冷冻胚胎指征：

1. 胚胎由2PN发育而成的胚胎。若胚胎较少，在患者要求下由OPN或1PN发育的胚胎也可冷冻，需向患者说明风险。

2. 胚胎卵裂球数目≥4个，胚胎评级Ⅲ级以上。

囊胚冷冻的指征：

1. 冷冻时间为Day5-Day6(极少Day7)。

2. 2PN，OPN或1PN发育而成的胚胎。

3. 囊胚发育到3-6期的囊胚。

4. 内细胞团和滋养层细胞评分≥3BC。

那么有些患者会问胚胎冷冻会降低临床妊娠率吗？

最新一项研究数据统计了20687名全胚冷冻患者进行冷冻移植的妊娠结局，结果显示患者的临床妊娠率为58.62%，而小于31岁患者的临床妊娠率为66.24%，与新鲜移植周期怀孕率类似。因此，冷冻移植并不会降低您的成功率。

 

胚胎解冻会不会解死呀？

经过反复多年的临床研究结果验证，冷冻胚胎解冻后的损害很小。目前我中心胚胎复苏率超过95%，解冻后死亡的概率极低，因此大家不用过度担忧，而且冻胚移植周期的临床妊娠率与新鲜周期移植相似，均在50-60%左右。

 冷冻移植会不会影响孩子的健康？

胚胎冷冻会影响宝宝的健康吗？从科学角度分析，冷冻的胚胎在零下196 ℃的情况下，其代谢几乎完全处于静止状态，不会衰老，所以，存储时间长短对其发育潜能及健康状况没有显著影响。原则上来讲，只要胚胎复苏成功，移植到女性子宫内，能够正常着床，一般情况下出生的“冻宝宝”没有问题。
